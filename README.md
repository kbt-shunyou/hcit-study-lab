# 医療情報技師 合格ラボ

医療情報技師能力検定試験（第25回・2027年8月22日予定）に向けた学習Webアプリです。
テキスト・問題演習・自己分析を1つのページで行えます。インストール不要で、スマホ・PCのブラウザで動きます。

## できること

| 画面 | 内容 |
|---|---|
| ホーム | 試験までの日数、今日の解答数、系ごとの進み具合、苦手な章、ワンタップ演習 |
| テキスト | 全17章（情報処理7・システム6・医学医療4）。重要／出題ポイント／時事チェック、章末○×ドリル、読了チェック |
| 問題演習 | 全135問（過去問再現90問＋オリジナル予想45問）。系・出典・重要度・章・学習状況で絞り込み。練習モード（1問ずつ解説）と模試モード（時間計測・最後に採点） |
| 自己分析 | 初回→直近の正答率と改善幅（系別・重要度別・出典別・章別）、日別正答率グラフ、学習状況の内訳、問題ごとの履歴 |
| 時事 | 出題予想ランキング、2027年度向け時事テーマ、過去3年の講評の要点 |
| 暗記 | 数字・年号、略語、各問題の「覚えるポイント」のフラッシュカード |

### 重要度
- **A 最重要**：講評で正答率が低かったテーマ、時事（ガイドライン第7.0版、医療DX、令和8年度改定など）
- **B 重要**：頻出の標準的な論点
- **C 基礎**：計算・用語など確実に取りたい基本

### 学習状況（自動判定）
未回答 → 要復習（最新が不正解）→ 学習中 → 定着（2回連続正解）。「おすすめ10問」は要復習・未回答の重要問題・時間が経った問題を優先して出題します。

## 学習記録について
解答履歴はブラウザ（localStorage）に保存され、外部には送信されません。別の端末へ移すときは「設定・バックアップ」で書き出し→読み込みしてください。

## GitHub Pages で公開する手順
1. このフォルダの中身をGitHubの新しいリポジトリ（例：`hcit-study-lab`）にアップロード
2. リポジトリの **Settings → Pages** で、Source を「Deploy from a branch」、Branch を `main` / `(root)` にして Save
3. 数分後に `https://<ユーザー名>.github.io/hcit-study-lab/` で開けます

## 問題・テキストを追加・修正するには
1. `src/content/` のデータを編集
   - `data_past.js`：過去問再現（年度別・系別）
   - `data_orig.js`：オリジナル予想問題・試験動向
   - `data_text1〜3.js`：テキスト各章、`data_text4.js`：時事特集・付録
2. `node src/build.js` を実行すると `index.html` と `data.js` が更新されます
3. コミットしてプッシュすれば公開ページに反映されます

問題の形式：`{ q:"問題文", c:["選択肢1",…,"選択肢5"], a:[正解番号], e:"解説", p:"覚えるポイント" }`（2つ選ぶ問題は `a:[1,3]`）

## 教材（Word）
`materials/` に同じ内容のWord版（過去問再現演習集・オリジナル予想問題集・合格テキスト）を収録しています。

## ご注意
- 過去問再現は、公式講評で公表された出題テーマに基づいて作り直した類題で、本試験の原文ではありません。本試験の問題文は南江堂『医療情報技師能力検定試験 過去問題・解説集』で確認してください。
- 制度・診療報酬・ガイドラインは2026年11月時点の情報です。受検前に厚生労働省・医療情報技師育成部会の最新情報を確認してください。
